# 小明智能体 · 中文待办清单

和小明用中文聊天，就能新增、查看、完成和删除待办。聊天和任务 API 共用本地清单。刷新页面或重启服务后，待办和完成状态仍可查询。

## 运行

安装 Node.js 24.12 或更高版本，在终端运行以下命令。

```sh
git clone https://github.com/yangchong379/todo-agent.git
cd todo-agent
npm ci
npm run dev
```

打开 <http://127.0.0.1:3000>。常见中文指令和下面的验收对话在没有 API Key 的情况下也能运行。

可以直接说「我晚上有个会议」「明天得去取快递」，小明会把明确的日程和行动计划加入待办，并在标题里保留时间。也可以用「还有哪些事没做？」查看待办，或用「我开完会了」标记完成。对多场匹配的会议，小明会请你指明是哪一场。

如果想让小明尝试理解更多口语说法，把 `.env.example` 复制为 `.env`，填写 `DEEPSEEK_API_KEY` 并重启服务。只有本地规则未识别的短消息才会发给 DeepSeek。模型只收到本轮用户消息，不会收到清单、任务 ID 或对话历史。模型调用会产生实际费用。更多用法见[本地开发指南](GETTING_STARTED.md)。

## 验收

建议在空清单中按顺序发送以下消息。

| 用户对小明说     | 预期结果                                   |
| ---------------- | ------------------------------------------ |
| 帮我记一下买牛奶 | 新增待办「买牛奶」                         |
| 再记一条取快递   | 清单里多了一条「取快递」                   |
| 我有哪些任务？   | 列出两条任务，并能看出各自的完成状态       |
| 牛奶买好了       | 把「买牛奶」标记为已完成，「取快递」仍待办 |
| 取快递这条删掉吧 | 删除「取快递」                             |
| 再给我看看清单   | 只剩已完成的「买牛奶」                     |

然后刷新浏览器，发送「再给我看看清单」，应仍显示已完成的「买牛奶」。停止并重新执行 `npm run dev` 后再问一次，结果应相同。也可以试试「帮我记一下洗衣服」和「衣服洗好了」，或发送「看看还没完成的任务」筛选待办。

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

## 扩展功能验收

| 发送给小明                     | 预期结果                   |
| ------------------------------ | -------------------------- |
| 帮我记一下准备汇报             | 新增主任务「准备汇报」     |
| 把准备汇报的截止日期设为今天   | 保存独立的截止日期         |
| 把准备汇报的优先级设为高       | 清单显示高优先级           |
| 把准备汇报的工作量设为中       | 清单显示中等工作量         |
| 给准备汇报加个子任务：整理数据 | 在主任务下新增子任务       |
| 看看准备汇报的子任务           | 显示子任务及完成状态       |
| 完成准备汇报的子任务整理数据   | 只把「整理数据」标为已完成 |
| 今天有哪些任务到期？           | 列出截止日期为今天的任务   |

也可以用「恢复准备汇报的子任务整理数据」重新打开子任务，用「把准备汇报的子任务整理数据改名为整理成本」改名，或用「删除准备汇报的子任务整理成本」删除。主任务和子任务的完成状态独立记录，删除主任务时会一起删除它下属的子任务。

截止日期支持「今天」「今晚」「明天」「后天」「下周一」和 `YYYY-MM-DD` 等表达。比如「帮我记一下今天交报告」会自动保存今天的日期。原有任务可以通过聊天补设日期。默认按香港时区计算「今天」，可在 `.env` 中设置 `TODO_TIME_ZONE` 覆盖。例如 `TODO_TIME_ZONE=Asia/Shanghai`。还可以问「有哪些逾期任务？」查看尚未完成的过期任务。

桌面右侧清单会随聊天操作更新，优先显示待处理任务，并标注子任务进度、截止日期、优先级和工作量。手机上可点顶部「清单」。刷新页面或重启服务后，扩展字段仍从原有的 `data/tasks.json` 读取。

## 实现

- 聊天可创建任务、按状态或日期查看清单、标记完成并删除。聊天清单按完成状态分组，组内优先显示较早到期和较高优先级的任务。
- 可以用任务原名、唯一的名称片段或「牛奶买好了」这类自然语序指明任务。删除同名任务时，可以说「把待办的报名讲座拿掉」。匹配不唯一时，小明会按状态列出候选，可以回复「第一条」选择。
- 重复记录同名的未完成任务会提示该任务已在清单里。重复完成会返回任务当前的完成状态。同名任务只有一条未完成时，可以完成它。每条消息处理一项操作。遇到纯代词、含糊或未识别的表达，可以带上任务完整名称重说一次。
- 聊天和 [OpenAPI 任务接口](server/openapi.yaml) 共用一个任务存储，数据保存在 `data/tasks.json`。小明根据存储操作的结果回复。可选的 DeepSeek 解析只提供意图，目标匹配、输入校验和读写仍由服务端完成。
